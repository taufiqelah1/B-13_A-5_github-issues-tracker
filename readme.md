1️⃣ What is the difference between var, let, and const?
Ans : In JavaScript, var, let, and const are used to declare variables, but they work differently. The difference is that var can be re-declared and updated, while let can be updated but not re-declared in the same scope. const cannot be re-declared or reassigned. Another difference is that var is function-scoped, whereas let and const are block-scoped. That's why we mostly use let and const in modern JavaScript.

2️⃣ What is the spread operator (...)?
Ans : The spread operator (...) in JavaScript is used to expand elements of an array or properties of an object. It helps us copy arrays, merge arrays, combine objects, and pass multiple values to functions. It makes our code shorter and easier to write.The spread operator (...) means take the values and spread them out.

3️⃣ What is the difference between map(), filter(), and forEach()?
Ans : map(), filter(), and forEach() are array methods used to work with array elements. The main difference is how they process the elements and what they return. The map() method creates a new array by modifying each element. The filter() method creates a new array with only the elements that meet a condition. The forEach() method simply loops through an array and performs an action without returning a new array.

4️⃣ What is an arrow function?
Ans : An arrow function is a shorter way to write a function in JavaScript. It was introduced in ES6 and uses the => symbol instead of the function keyword. Arrow functions make code shorter and easier to read. They are commonly used with array methods like map(), filter(), and forEach().An arrow function does the same basic job as a regular function, but uses => and shorter syntax.

5️⃣ What are template literals?
Ans : Template literals are a way to write strings in JavaScript using backticks (` `) instead of single (' ') or double (" ") quotes. They were introduced in ES6 (2015) and make it easier to insert variables, expressions, and write multiline strings. We can easily insert variables and expressions using ${} and write multiline strings without using \n. They make our code cleaner and easier to read.
